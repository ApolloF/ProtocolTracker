**ProtocolTracker is now SteroidTracker.** Track TRT, HRT, peptides and bloodwork. Offline.

- **Same app, new name.** Install **SteroidTracker-<version>.apk** over ProtocolTracker; it updates in place and your plan, logs, journal and settings stay. The app id is unchanged (`com.apollof.protocoltracker`).
- **Backups:** backups saved by ProtocolTracker restore as before. New backups and reports are named `steroidtracker-…`; what is inside them is unchanged.
- **Bloodwork import:** an AI prompt copied before the update still works, and the app still recognises it when it is pasted back by mistake.
- **Obtainium and other update tools:** this release has the same APK under both names, `SteroidTracker-<version>.apk` and `ProtocolTracker-<version>.apk`, so existing setups keep updating. To stop Obtainium asking which file to install, set its APK filter to `SteroidTracker-.*\.apk`. The repository moved to github.com/ApolloF/SteroidTracker; the old address redirects.
- The phase name example now reads "e.g. Start, Maintenance, Taper".
