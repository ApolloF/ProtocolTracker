Dev pre-release. One APK:

- **ProtocolTracker-Dev-v0.5.0-dev.11.apk** – the dev build. Installs next to the regular app with its own data and a purple icon, and updates an earlier dev build in place. The regular app stays at 0.4.0.

## Changes (dev build)
- **Days off on Today:** a day without doses shows "Nothing due today" and the next one, for example "Next: Tirzepatide · Mon, Oct 5, Morning".
- **Missed and adherence count from your first logged dose.** Reports (HTML and Markdown) and Journal's adherence no longer count plan days from before you started using the app, which after the web history import made years of "missed" doses.
- **Long notes** show their first four lines in Journal and on Today; tap one to read or edit all of it.
- **Settings:** the Times of day summary uses your clock format ("Morning 8:00 AM").

## For development
- New guards: every tappable element on the four tabs is at least 48 dp (`TouchTargetTest`), and warning text meets contrast in every colour scheme.

## Data
No database or backup change: database version 4, backup format `protocoltracker-backup-2`.
