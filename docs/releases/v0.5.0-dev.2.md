Dev pre-release. One APK:

- **ProtocolTracker-Dev-v0.5.0-dev.2.apk** – the dev build. Installs next to the regular app with its own data and a purple icon, and updates an earlier dev build in place. The regular app stays at 0.4.0.

This release imports your history from the CycleTracker web app.

## Import your web app history (dev build)
1. **Get the full export.** Open `<your web app address>/api/export/full?token=<export token>` in the phone's browser (the token is the server's `EXPORT_TOKEN`; an `Authorization: Bearer <token>` header works too) and save the page as a `.json` file on the phone. The Logs page's "Export AI Review" file also works, but holds less.
2. **Import it.** In the dev build, go to Settings › Export and data › Import CycleTracker export and pick the file.
3. **Check and confirm.** "Import web app history?" shows the time span, how many entries of each kind it will add, what it leaves out and any warnings. There is no undo, so save a backup first if you want a way back.

What it brings in, as Journal entries:
- **Blood pressure** readings (with pulse when there is one).
- **Notes.** Very long notes are shortened, with a warning.
- **Symptoms**, including mood and the old mood-only logs.
- **Bloodwork.** The web app's markers keep their exact values, and a lab's own range when it differs from the web app's default. Other tests, such as prolactin, appear under "Other tests" as printed.

What it skips:
- Dose logs, checklist ticks, weekly notes, settings and lab PDFs (a draw with a PDF comes in without it).
- Impossible values, such as a blood pressure or lab value outside the plausible range. The dialog lists them under warnings.
- A web draw on a day that already has a draw in the app (the app's draw is kept, with a warning).

Importing the same file again adds nothing ("Nothing new to import from this file."); entries already in the app, or entered by hand within 15 minutes with the same values, are not duplicated. The regular app still rejects this file.

## Other changes
Mostly groundwork for later dev releases, not visible yet:
- Bloodwork import from lab reports: the marker vocabulary, reading pasted result blocks, and the prompt for the AI chatbot (see [docs/BLOODWORK_IMPORT.md](../BLOODWORK_IMPORT.md)).
- Trends: marker history, time since the last draw, and 7-day blood pressure averages.
- Injection sites: the site list and the rotation rule that suggests the next site.
- Several journal entries are saved or deleted in one step, so an import either saves completely or not at all.

## Data
No database or backup format change (database version 3, backup format `protocoltracker-backup-2`). Imported entries are ordinary Journal entries and are included in backups.
