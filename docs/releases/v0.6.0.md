**ProtocolTracker is now SteroidTracker.** Track TRT, HRT, peptides and bloodwork. Offline.

Install **SteroidTracker-v0.6.0.apk** over ProtocolTracker 0.5.x; it updates in place and your plan, logs, journal and settings stay. The app id is unchanged (`com.apollof.protocoltracker`).

## New name
- Backups saved by ProtocolTracker restore as before. New backups and reports are named `steroidtracker-…`; what is inside them is unchanged.
- A bloodwork AI prompt copied before the update still works.
- **Obtainium and other update tools:** this release has the same APK under both names, `SteroidTracker-v0.6.0.apk` and `ProtocolTracker-v0.6.0.apk`, so existing setups keep updating. To stop Obtainium asking which file to install, set its APK filter to `SteroidTracker-.*\.apk`. The repository moved to github.com/ApolloF/SteroidTracker; the old address redirects.

## Levels
- **New level model:** the estimated curves use the kinetics of a public sheet of compiled PK parameters (sources in `docs/MODELS.md`). Several compounds that only had a relative curve (Tren, Masteron, Primo, Dbol, Tbol, Superdrol, DHB, MENT, Test PP/Iso/Dec) now have one in ng/dL. Estimated levels are lower than in 0.5.x; your logged doses are not changed.
- **Adjust level:** on a group's detail screen, scale its estimate by −90 % to +100 %, for example to line it up with your own lab results. It changes the curve and its figures only, never your doses, plan or lab results.
- **New presets:** Test U MCT; testosterone gel and sublingual; estradiol gel, cypionate and valerate; progesterone oral and vaginal; SARMs and cardarine.
- Corrected ester fractions for Deca, DHB and Nebido.

## Bloodwork and symptoms
- Results are flagged only against the range printed by your lab. Results without a lab range show no flag.
- A typed value that is impossible for the marker and unit is marked and cannot be saved.
- Symptom headings read "Often listed as low-estrogen signs" and "Often listed as high-estrogen signs".

## Other changes
- On first start the app says what it is and is not (a personal log, not medical advice, not a medical device); Settings › About shows it again with the privacy summary. Privacy policy: PRIVACY.md.
- Exact-time doses stay taken after a time-zone or clock change, or a time edit.
- Reminders that came due while the phone was off are posted once after it starts.
- Levels uses the day start (default 4:00) to pick the current phase.
- Layout fixes for narrow screens and large fonts. The phase name example reads "e.g. Start, Maintenance, Taper".
