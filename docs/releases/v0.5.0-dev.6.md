Dev pre-release. One APK:

- **ProtocolTracker-Dev-v0.5.0-dev.6.apk** – the dev build. Installs next to the regular app with its own data and a purple icon, and updates an earlier dev build in place. The regular app stays at 0.4.0.

## Changes (dev build)
- **Earlier… never lands in the future.** In the dose, blood pressure, note and symptom sheets, a time picked under **Earlier…** is the latest such moment that has passed: 11:00 PM picked at 00:30 is yesterday 11:00 PM, not tonight. The chip then names the day, for example "Yesterday 11:00 PM". Editing an entry keeps its own day unless the time would be after now.
- **Journal › All shows bloodwork as one row:** "Bloodwork · last draw 3 days ago · 2 out of range". Tap it for the Bloodwork chip with every marker; tap a marker there for its chart.
- **The selected Journal chip scrolls into view.** After an import Journal opens on Bloodwork, which used to sit off-screen on narrow phones.
- **Check results says what a tap does:** "Tap a result to leave it out." at the top; a result you left out reads "Left out. Tap to keep.", and the line above Save names it ("Hematocrit is left out.").
- **Bloodwork import:** when one answer holds two blocks (for example a chatbot's correction), a later value of an unlisted test (Vrij T4, ferritine) replaces the earlier one in the same unit, as it already did for listed markers. Values in another unit (% and absolute) stay separate.

## How to check
1. Journal › + › Note › **Earlier…** after midnight: pick a time later than now; the chip reads "Yesterday …" and the note lands on yesterday.
2. Journal › All: one Bloodwork row; tap it.
3. Log › Bloodwork › Import results › Paste answer: the caption is at the top; tap a result and read the line above Save.

## Data
No database or backup change: database version 4, backup format `protocoltracker-backup-2`.
