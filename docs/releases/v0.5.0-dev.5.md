Dev pre-release. One APK:

- **ProtocolTracker-Dev-v0.5.0-dev.5.apk** – the dev build. Installs next to the regular app with its own data and a purple icon, and updates an earlier dev build in place. The regular app stays at 0.4.0.

This release fixes the crash when opening Bloodwork and problems found by running the dev build on an Android emulator. v0.5.0-dev.1 to dev.4 crash as soon as Bloodwork opens; update to this build.

## Fixes
- **Bloodwork no longer crashes.** Opening Log › Bloodwork (or a Bloodwork entry) closed the app on every phone. One text pattern used to read lab names was valid in the tests but not on Android. Bloodwork, Import results and the marker sheets open again.
- **Headers sit at the right height.** Today, Plan, Levels and Journal had an extra empty band under the status bar; the header now starts right below it.
- **Long notes can be saved.** A note of many lines (for example a pasted text) pushed Cancel and Save off the screen. The text field now stops growing and scrolls, and the sheet scrolls too. This also applies to the regular app's data, not its look.
- **Undo goes away.** After importing bloodwork or deleting a Journal entry, "Undo" stayed at the bottom of Journal until you tapped it; a late tap undid the import. It now disappears after about ten seconds.
- **A new plan item does not start with missed doses.** Adding a compound listed yesterday's doses under Missed on Today. A new item's **Starts** date is now today (or the start of a later phase); change it under the item's dates if you started earlier.
- From the previous build's backlog: a dose logged from the Log dose sheet without changing the amount is saved as the plan's amount, not a rounded copy, so Today and Journal no longer show "(plan 35.71 mg)" for an unchanged dose; the Site row's expand chip reads **All sites**. The bloodwork import asks about request, result and validation dates instead of taking them as the draw date, and reads TSH and prolactin in mIE/l.

## How to check
1. Log › Bloodwork opens the sheet; **Import results** › **Paste answer** with a chatbot answer shows Check results; **Save** lands in Journal under the Bloodwork chip; tap a marker row for its chart.
2. Plan › Add › any compound › Save: Today shows no Missed card for it.
3. Journal › + › Note: paste a long text; Save stays reachable.
