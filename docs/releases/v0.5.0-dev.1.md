Dev pre-release. One APK:

- **ProtocolTracker-Dev-v0.5.0-dev.1.apk** – the dev build. Installs next to the regular app with its own data and a purple icon, and updates an earlier dev build in place. The regular app stays at 0.4.0.

This release lays the groundwork for importing lab reports with help from an AI chatbot (see [docs/BLOODWORK_IMPORT.md](../BLOODWORK_IMPORT.md)). The import itself comes in a later pre-release.

## Changes (dev build)
- **Bloodwork results keep what the lab printed:** the lab's own reference range, values reported as "<0.3" or ">90", and tests that are not in the app's marker list ("Other tests"). Flags use the lab's range when there is one; the Journal marks such ranges "(lab)".
- **Bloodwork sheet:** shows "Lab range" for results with a lab range, "Reported as <0.3 IU/L" for such values (typing a number replaces it), and an "Other tests" section.
- **Editing a draw** no longer changes values you did not touch. Before, opening and saving a draw could round stored values or drop details.
- **Reports** (HTML and Markdown) show lab ranges, reported values and other tests, and say when a range is the lab's own.
- **Journal:** "1 result" instead of "1 results".

## Under the hood
- Dev builds are published as pre-releases from tags like `v0.5.0-dev.1`, with only the dev APK; CI checks that the version shown in Settings matches the tag.
- Tests check that neither build asks for network access, and that dev-only entry points stay out of the regular app.

## Data
No database or backup format change (database version 3, backup format `protocoltracker-backup-2`). Backups move between this build and 0.4.0 as before.
