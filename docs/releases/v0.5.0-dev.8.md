Dev pre-release. One APK:

- **ProtocolTracker-Dev-v0.5.0-dev.8.apk** – the dev build. Installs next to the regular app with its own data and a purple icon, and updates an earlier dev build in place. The regular app stays at 0.4.0.

## Changes (dev build)
- **Levels: slide to read, always.** Slide one finger along any chart to read the level and see what was logged near that time; ticks mark days and doses as you pass them. A tap reads one point. Two fingers pan and zoom; a vertical swipe that starts on a chart scrolls the page. Changing the range or tapping Back to now clears the reading.
- **Levels overview is a glance:** only the range row and the charts. The Logged + plan / Logged / Plan only row and the figures (now, steady range, steady average, time to steady) are on each compound's detail screen: tap its name.

## Removed from the dev build
- **Compare mode** and the **Settings › Experimental** page. Scrubbing no longer needs a switch, so nothing experimental is left. The regular app keeps both for now.

## Data
No database or backup change: database version 4, backup format `protocoltracker-backup-2`. The stored Experimental switches stay in the settings file and are ignored by the dev build.
